## Oversigt: “Postgres kan meget mere end SQL”

Denne mappe er tænkt som dit undervisningsmateriale til at vise, hvad PostgreSQL kan, når man tænder udvidelser.

### Hvad eleverne får ud af det

- **Forståelse**: Postgres er en platform, ikke kun en database.
- **Praksis**: De lærer at aktivere udvidelser pr. database og bruge dem sikkert.
- **Værktøjer**: De ser, hvordan indekser, planlægning (cron), geodata og vektor-søgning hænger sammen.
